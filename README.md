## About Me

I am a computer engineer and product-focused software developer based in Türkiye.

As the founder of **Mobiza**, I design and develop digital products from the initial idea to production. My work covers product architecture, backend systems, mobile applications, web platforms, game development, databases, deployment and ongoing product operations.

I enjoy building products that solve real problems, scale reliably and provide a polished user experience.

```text
Idea → Product Design → Architecture → Development → Deployment → Growth
```
